# Pygame Space Shooter

A simple space shooter game created using Python and Pygame.

## Features

- Player movement
- Shooting lasers
- Meteor spawning
- Collision detection
- Score system
- Lives system
- Scrolling star background
- Meteor Explosion

## Installation

```bash
pip install pygame
```

## Run

```bash
python space_shooter_improved.py
```
